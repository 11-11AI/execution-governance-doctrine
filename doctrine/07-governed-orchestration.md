# 07 — Governed AI Orchestration

**Agent workflows run only inside approved boundaries.**

Every tool call, model action, and orchestration event in an agentic workflow
is gated before it occurs. Identity anchors (including DNS-anchored agent
identity such as DNSid), policy, and runtime state are evaluated per event —
so autonomous systems remain inside approved policy, trust, and runtime
boundaries even when composed of many agents acting across organizational
lines.

Identity standards answer *who owns the agent*. Execution Governance answers
*whether it may act* — and proves the answer.
